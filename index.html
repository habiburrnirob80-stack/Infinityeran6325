উইথড্র কত সময়ে পাবো?

রিকোয়েস্ট পেন্ডিং → প্রসেসিং → সাকসেসফুল — এডমিন যাচাই করে পেমেন্ট পাঠান। স্ট্যাটাস Wallet পেজে লাইভ দেখা যায়।

রেফার বোনাস কখন পাবো?

আপনার রেফার করা বন্ধু জয়েন ভেরিফিকেশন/টাস্ক কমপ্লিট করলে (এডমিনের সেট করা রুল অনুযায়ী) আপনার ব্যালেন্সে বোনাস যোগ হবে।

ব্যালেন্স কাটা গেছে কিন্তু টাস্ক হয়নি?

ইন্টারনেট সমস্যায় হতে পারে — Admin Support-এ আপনার ID দিয়ে মেসেজ দিন, এডমিন দ্রুত ঠিক করে দেবেন।

প্রমোশন সার্ভিস নিতে চান? 📢
আপনার টেলিগ্রাম চ্যানেল/গ্রুপ, YouTube, Facebook, TikTok — যেকোনো সোশ্যাল মিডিয়া প্রমোট করতে অ্যাডমিনের সাথে চ্যাট করুন। ১০০% রিয়েল সার্ভিস গ্যারান্টিড।

ছবি সেভ করুন 📸

নিচের ৯:১৬ রসিদ ছবিটি লম্বা করে চেপে ধরুন (long-press) → "Save Image / ছবি সেভ করুন" সিলেক্ট করুন। Telegram-এর ভেতরে অটো-ডাউনলোড না হলে এভাবেই গ্যালারিতে সেভ হবে।
